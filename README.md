# Sheenaz's Learning Hub

A kid-friendly home page for Sheenaz with links to her learning materials.

## What's here

- **`index.html`** — Home page with cards linking to each resource.
- **`math_sol.4.ns.3/practice/`** — Interactive practice sheets for Virginia SOL 4.NS.3 (fractions). Each sheet shows the original worksheet plus input boxes where she can type answers; answers autosave in the browser.
